### 📈 銘柄データを用いた機械学習・自動取引フレームワーク
趣味で開発した、株価データを用いた未来予測および自動取引シミュレーションのフレームワークです。

#### 1. 開発したシステム（2つのフレームワーク）
* **株価未来予測モデル:** pandasで時系列データを前処理し、約900銘柄の過去の株価ビックデータおよびDTWを用いて1つのコモディティ銘柄の株価トレンドを予測。
https://github.com/hatuki437/1540/blob/main/%E5%AE%8C%E6%88%90%E3%83%93%E3%83%83%E3%82%AF%E3%83%87%E3%83%BC%E3%82%BF%E6%9C%AA%E6%9D%A5%E4%BA%88%E6%B8%AC%20CL%3DF%E7%89%88.ipynb

* **自動取引アルゴリズム:** LightGBMを用いた予測結果に基づき、一定のルール（ロジック）に従って擬似的な売買を行うシミュレーション環境。
https://github.com/hatuki437/1540/blob/main/LGPH%E3%83%AC%E3%82%B8%E3%83%BC%E3%83%A0%E3%83%95%E3%82%A3%E3%83%AB%E3%82%BF%E3%83%BC.ipynb


#### 2. 使用技術
* **言語:** Python
* **主要ライブラリ:** pandas, scikit-learn, LightGBM,tslearn dtw
* **開発手法:** LLM（Gemini）をペアプログラマとして活用し、プロンプトエンジニアリングを用いた高速なプロトタイピングを実施。
